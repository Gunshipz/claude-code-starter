# claude-code-starter

A starter kit for Claude Code on Windows, built so Claude does the setup itself.

After installing Claude Code and signing in, paste this into Claude:

```
Download https://raw.githubusercontent.com/Gunshipz/claude-code-starter/main/SETUP.md with PowerShell and read all of it, then follow it to set up my computer. Do every step yourself.
```

| File | What it is |
|---|---|
| `SETUP.md` | Step-by-step instructions written for Claude: apps, browser helpers, skills, craft tools, house rules, with restart checkpoints and a resumable checklist |
| `CLAUDE-starter.md` | Starter house rules for `~/.claude/CLAUDE.md` |
| `statusline.js` | The ribbon: model, folder, context use, 5-hour and weekly limits with reset countdowns |
